# PolyglotScan website

SolidStart static (`server.preset: static`) + [solid-ui](https://github.com/stefan-karger/solid-ui) primitives (Kobalte). Black/white chrome with scan-bar green.

```powershell
pnpm install
pnpm dev
pnpm build
```

Output: `.output/public`
